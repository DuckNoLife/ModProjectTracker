# Security Policy

## Reporting a vulnerability

If you discover a security issue, please report it privately instead of opening a public issue.

- Use GitHub Security Advisories if available, or contact the repository owner directly.
- Include a clear description of the issue, affected feature, and any safe reproduction steps.
- Do not include secrets, API keys, tokens, or private credentials in the report.

## Scope

This project may use cloud services, Google services configuration, and other API-based features. Treat all secret values and service credentials as sensitive.

## Response

A report will be reviewed as soon as possible and you may be asked for additional details if needed.
